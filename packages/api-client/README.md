# packages/api-client

TypeScript client **generated** from the backend's OpenAPI spec, so the TS apps can't drift
from the API contract. Never edit `openapi.json` or `src/schema.d.ts` by hand; regenerate them.

```sh
make api-client   # exports the spec from apps/api (needs Docker), then regenerates src/schema.d.ts
```

- `openapi.json`: the spec, written by `OpenApiSpecExportTest` in `apps/api`.
- `src/schema.d.ts`: types generated by `openapi-typescript`.
- `src/index.ts`: `createApiClient(baseUrl, getToken?)`, a typed `openapi-fetch` client that adds
  the bearer token to each request.

Both generated files are committed so the apps build without Java; CI regenerates them and fails
if they differ.
